### Test fix

The new DB-backed tests initially failed because the `db` fixture created an isolated in-memory
engine while `construct._get_db()` imported the module-level `AsyncSessionLocal`, which points to
the workspace `littleman.db`. Two fixes:

1. `tests/conftest.py` `db` fixture now monkeypatches `littleman.db.connection.AsyncSessionLocal`
   to the test engine's session factory, routing all module-level session creation to the test DB.
2. `construct._run()` was deadlocking when called from pytest-asyncio (it blocked the loop's own
   thread waiting for a coroutine scheduled on that same loop). Replaced the in-loop wait with a
   `ThreadPoolExecutor` worker that runs `asyncio.run(coro)` on its own event loop.
